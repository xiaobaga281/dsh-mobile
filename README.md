# DSH Mobile

**DeepSeek Harness 的手机客户端** —— 把桌面端 AI 助手装进口袋：出门在外用流量，也能连回家里的电脑，接着电脑上的会话继续聊。

> 本仓库仅发布安装包与说明，不包含源代码。

## 这是什么

DSH Mobile 是一款 Android 客户端，与桌面端 DSH（DeepSeek Harness）配套使用。它不是一个独立的聊天 App，而是你电脑上 DSH 的「随身遥控器 + 第二屏幕」：

- 在家：连同一 WiFi，扫码级配置，一键连上电脑；
- 出门：手机走流量，通过中继也能连回电脑（中继可自建或部署在任意公网服务器）；
- 电脑端的会话、模型、任务，手机上都能看到、能继续。

## 核心功能

### 会话同步
- 手机端浏览、接续电脑端的对话，上下文无缝衔接
- 流式输出：思考过程、回复内容、工具调用全程实时可见
- 深度求索风格动画：鲸尾 APNG 呼吸摆动，与桌面端同构

### 电脑联动（中继配对）
- 「连接电脑」三步完成：填中继地址、房间号、口令
- 中继协议极简：请求/应答透传，口令即房间密钥，电脑端签发设备令牌
- 支持 30s 心跳 + 分步探测诊断：中继可达性 / 电脑应答逐项显示，连不上一眼看出卡在哪一环
- 多设备配对管理：桌面面板可查看在线状态、移除设备、重置配对

### 模型与参数
- 读取电脑端模型目录，手机上直接切换模型与思考强度
- 本地音色扫描：使用设备自带 TTS 音色，云端音色可开可关
- 音色面板支持自定义调参：音高（含负向大范围）、倍速等
- 语音律动处理：一阶低通拆分「体声 / 气声」，更自然的陪伴式朗读

### 实用工具
- 文件浏览：读取电脑端工作区文件
- 任务查看：电脑端后台任务进度随身可见
- 通知联动：电脑端运行通知推送到手机
- 明暗主题跟随系统

## 下载安装

前往 [Releases](../../releases) 页面下载最新的 `DSH-Mobile-x.x.x-release.apk`：

1. 下载 APK 到手机，点击安装（允许「安装未知来源应用」）；
2. 打开 App → 设置 → 连接电脑；
3. 照抄桌面端插件面板上的「中继地址 / 房间号 / 口令」三项，点连接。

> 桌面端需在 DSH 中启用 Mobile Link 插件并启动联动。

## 使用要求

- Android 8.0（API 26）及以上
- 桌面端 DSH（Windows / macOS / Linux）并启用 Mobile Link 插件
- 网络要求：
  - 同一局域网：中继填电脑的局域网地址即可；
  - 跨网（流量 / 不同 WiFi）：需要一台两端都能访问的公网中继（`relay` 服务为独立单文件 Node 程序，可自行部署到任意 VPS）。

## 隐私与安全

- 不含任何遥测、统计 SDK，不收集任何数据
- 会话数据默认存本机；连接电脑时数据经中继加密口令通道传输
- 本仓库不提供源代码，安装包按「现状」提供
