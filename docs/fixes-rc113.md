# rc.113 修复清单（2026-10-26）

本版修复五类问题，全部附实测。完整评分口径见仓库 README 附录 B。

## 1. 签名根除 keytool / PaX 拦截

| | 修复前 | 修复后 |
|---|---|---|
| 链路 | rootfs 里 keytool 起 guest JVM | 宿主进程内 JCA 生成（手写 DER） |
| 失败率 | 20~35%（proot 下 mprotect(PROT_EXEC) 被 W^X 随机拦截） | **0** |
| 签名段耗时 | ~15s | **1.4s** |
| 产物 | keystore + 口令 | PKCS#8 + X.509 DER（apksigner --key/--cert） |

`-Xint` 实测更差（2/6 vs 4/6）：解释器启动同样要生成 stub——RWX 匿名内存绕不开，
所以换掉的是「生成签名这件事根本不需要 guest JVM」。

## 2. 语音消息被静默丢弃

识别完成后的自动发送撞上「上一轮还在生成」时直接 return——文字发送按钮有入队处理，
语音这条入口什么都没做。改为同款入队 + toast 提示。端到端实测：识别回调 → 发送 → 回复。

## 3. 页面重载后流式轮次失联

WebView 渲染进程内存压力下被回收会自动重载（模拟器实测两次）；内核轮次在原生侧
继续跑，但新页面已丢失轮次 id，事件全被丢弃。修复：`AgentBridge.agentActive()` +
页面就绪时重新认领。端到端实测：流式中强制重载 → 新页面自动接回并继续渲染。

## 4. 发送新消息后视口跳到历史

重建对话流的中间帧滚动高度塌陷（scrollTop 被钳到 0）+ 非跟随态发送不滚动。
改为重建同帧贴底 + 发送一律强制贴底。

## 5. 界面切换视觉卡顿

切换动画期两屏互为背景重绘 + 层内 10 处 backdrop-filter 逐帧重采样。
改为动画期提升合成层（will-change）并暂停玻璃模糊（结束即恢复）。

## 验证方式

端到端全部走真实 UI（CDP 驱动输入框与按钮）：本地模型
（llama.cpp + MiniCPM 1B，宿主机 8792 端口）。单测 395 → 403 全绿。
