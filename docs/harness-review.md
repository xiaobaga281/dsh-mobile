# dsh-mobile Harness 差距审查（六维评分 · 滚动更新）

> 基座对标：DeepSeek Harness 桌面端 `v0.2.1-rc.2`（`D:/1/dsh/deepseek-harness-dsh-v0.2.1-rc.2/packages/`）。
> 原则：语义对齐桌面，实现按手机平台重写；前端玻璃材质设计主调不变。
> 评分口径：每维 0–10，证据来自源码走读 + 模拟器实证（会话日志 `files/kernel/sessions/*.v2.jsonl`）。

## 六维定义

| 维度 | 考什么 |
|---|---|
| A 工具与执行 | 工具覆盖、并行/屏障、超时、spill、结果质量 |
| B 上下文工程 | 系统提示词装配、动态上下文、压缩、缓存友好性 |
| C 循环与规划 | 多步循环、steering、todo/goal/plan、子代理/团队、重试 |
| D 可靠与安全 | 守卫/审批/沙箱、崩溃恢复、日志即上下文、降级路径 |
| E 移动端杠杆 | 手机独有能力的 harness 化程度（操控/语音/相机/定时/造 App） |
| F 性能与资源 | 流式平滑、首音/首字、token 开销、内存与启动 |
